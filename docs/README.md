# Documentation Index

This directory keeps project-level notes that are not tied to one ROS package.

| File | Purpose |
| --- | --- |
| `backlog.md` | Personal research and implementation backlog migrated out of the repository root |
| `design-history/` | Historical design specs and implementation plans |
| `mi-gels-workflow.md` | Current Mi-Gels collection workflow and common launch commands |
| `repository-cleanup.md` | Cleanup notes and proposed boundaries between mainline, legacy, and data output |

Package-specific documentation should stay in the relevant package directory,
for example `src/sensor_data_collection/README.md`.
